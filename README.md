# Web Engineering Lab

Lab project for **Web Engineering**

**Author:** Rayyan Hurain

## Structure

```
web-engineering-lab
├── public/      HTML, CSS and JavaScript served to the browser
├── tests/       automated tests
└── README.md
```

## Getting started

```
npm install
npm start        # serves public/ on localhost
npm run lint     # ESLint
npm run format   # Prettier check
```
